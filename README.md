## Overview
This repository tracks the environment lockfiles and run metadata for Practical 01 of SCSE3040 (Machine Learning Operations), covering deterministic random seeding, SHA-256 data fingerprinting, dependency pinning, and local-to-remote Git workflows.

## Files
- `requirements.txt` — Full pinned environment dependencies (`numpy`, `pandas`, `scikit-learn`, `matplotlib`).
- `my_requirements.txt` — Minimal production dependencies (`numpy`, `pandas`, `scikit-learn`) created in Task T2.
- `run_info.json` — Experiment manifest recording Python version, seed, dataset row count, SHA-256 checksum, and library versions.
